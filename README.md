# Zamy – E-commerce Website

Zamy is a responsive e-commerce web application built with Angular 19, TypeScript, TailwindCSS and REST API.

## Features
- Product listing by category
- Product detail page
- Shopping cart with localStorage state management
- Checkout form
- Admin login page
- Admin product management
- Responsive UI for desktop and mobile
- REST API integration
- Frontend deployed on Vercel
- Backend deployed on Render

## Tech Stack
Angular 19, TypeScript, RxJS, TailwindCSS, Ng Zorro, REST API, Vercel, Render
